## What i learned with this game?
- How work with arrays
- How work with functions (def) and his parameters
- How work the if statements
- And how to integrate distinct methods together

# The step by step for the game
1. Build an array for the table, and strings for the players simbols
2. Before of the main game: Build the actions that will you need on the game
   - A method to show a polishied table
   - A method to Let the players make moves on the table
   - And a function to verify is there is a winner
3. Now you are ready to build the main game. You can do it by yourself, as you want: Use whiles, ifs and input methods!
